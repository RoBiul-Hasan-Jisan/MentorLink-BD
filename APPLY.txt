MentorLink BD - Career tab, pathway map, Projects & GitHub, plan review, help finder, department analytics

2. backend: npm test            (DB-free suites: npx jest tests/career_features.test.js tests/career_api.test.js)
3. backend: npm run seed:demo   (23 verified demo mentors + demo projects, a demo GitHub link and a plan review request)
